# 🚀 William Conceição | Full Stack Portfolio

Este é o repositório do meu portfólio profissional, desenvolvido com o ecossistema mais moderno do React. O objetivo é apresentar meus projetos, experiências e habilidades técnicas de forma dinâmica e performática.



## 🛠️ Tech Stack

- **Framework:** [Next.js 14 (App Router)](https://nextjs.org/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Animações:** [Framer Motion](https://www.framer.com/motion/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Deploy:** [Hostinger](https://www.hostinger.com.br/) / [Vercel](https://vercel.com/)

## 🏗️ Estrutura do Projeto

```text
src/
├── app/          # Rotas e Layouts (Next.js 14)
├── components/   # Componentes modulares e reutilizáveis
├── constants/    # Configurações globais e textos do LinkedIn/GitHub
├── lib/          # Funções de integração com API do GitHub
